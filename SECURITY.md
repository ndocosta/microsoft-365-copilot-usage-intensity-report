# Security policy

## Supported version

Security fixes are applied to the latest version on the default branch.

## Report a vulnerability

Do not disclose security vulnerabilities in a public issue. Use GitHub's
**Security > Report a vulnerability** option when it is enabled. If private
vulnerability reporting is unavailable, contact the repository owner through
the contact method on their GitHub profile before sharing technical details.

Include the affected component, impact, reproduction steps, and any suggested
mitigation. Do not include real tenant data, credentials, tokens, certificates,
or personal information.
